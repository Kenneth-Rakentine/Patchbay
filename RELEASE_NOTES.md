Patchbay: a diagram editor for hardware studio rigs.

**New in 1.2.0:** the legend block shows each cable name in its own cable colour and updates live. Use Insert legend block (Board panel) to add one.

**1.1.0:** import Whimsical diagrams. Copy as SVG in Whimsical, then press Ctrl+V on the Patchbay canvas.

**Downloads**
- `Patchbay-Setup-*.exe`: Windows installer
- `Patchbay-Portable-*.exe`: runs without installing

Windows may show a SmartScreen warning because the app isn't code-signed. Choose **More info → Run anyway**.

Boards in the desktop app are stored separately from the website. Use **Backup & import** to move them across.

Prefer no install? Use it in the browser: https://kenneth-rakentine.github.io/Patchbay/
