    Backup & import

    Boards save automatically in this browser. Keep a backup file so you can move them to another computer or restore them later.

    Back up all boards

    File downloads (.json, .svg, .png) appear when you run Patchbay from your own copy or GitHub Pages. Here, use Copy backup and paste it into a text file.

    Import from Whimsical

    In Whimsical, select everything on the board (Ctrl+A), right-click and choose Copy as SVG. Then press Ctrl+V anywhere on the Patchbay canvas, or paste it here. It comes in as a new board, so nothing you have is touched.

    Import boards

    Board image

    Right-click the image and choose “Save image as”, or copy it straight into a message.

    Share link

    Anyone who opens this link gets their own editable copy of this board. Nothing is uploaded anywhere: the whole board is packed into the link.
